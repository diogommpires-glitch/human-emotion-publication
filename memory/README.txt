Human Emotion memory
====================

The interactive app stores manually entered people and saved episodes in this browser's
local storage on this computer. It does not upload them. The optional reference picture
is resized in the browser and saved with that local profile; the app does not identify,
match, or analyze faces. Only add pictures you have permission to keep.

Use Export memory in the app to make a JSON backup. That backup includes any pictures
you attached, so keep it private. Import memory restores a backup. Clear memory removes
the app's saved local entries from this browser. The browser's local storage is not
encrypted by this app.

This folder is for human-readable schemas and future hand-curated memory files. The
interactive browser app cannot silently write into this folder; export a backup and
place it here manually if you want a file copy.
